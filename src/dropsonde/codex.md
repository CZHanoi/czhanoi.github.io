## 转换技

①ChatGPT→Aizex

(第一次见使用见[下方](#Aizex的接口))

```bash
cd /Users/hanoi/.codex
mv config.toml config.toml.bak
mv config.toml.bak2 config.toml
```

②Aizex→ChatGPT

```bash
cd /Users/hanoi/.codex
mv config.toml config.toml.bak2
mv config.toml.bak config.toml
```

（一句话总结就是我现在的命名逻辑是，直接对接我ChatGPT账号的是`config.toml.bak`，Aizex账号的是`config.toml.bak2`，需要使用谁就把其改名为`config.toml`就好了）
